# Workspace shell override

These rules apply to every Command, CRM, Sales, Finance, Operations, People,
Service, Intelligence, and Settings workbench.

## Layout

- Fixed left navigation rail with nested, expandable submodules.
- One main scroll canvas, maximum 1440px content width.
- A 12-column grid is allowed inside a workbench for KPIs, charts and tables;
  the page itself remains a calm single canvas.

## Visual hierarchy

1. Page heading and one clear task.
2. KPI strip with Indian currency and counts.
3. Source-linked charts (line, bar, or donut) with value legends.
4. Action/exception queue.
5. Detailed controls and evidence.

Use blue-white surfaces with navy ink. Amber is reserved for attention and
orange for the primary action. Keep headings visibly larger than body text.

## Interaction and safety

Every button opens a real destination or is explicitly disabled with a reason.
Show loading after 300ms, recoverable errors with a next step, permission
states, and honest empty states. Never use fake charts, fake map pins, or demo
sales in the live/imported retail workspace.
