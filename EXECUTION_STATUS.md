## Architecture decisions held

- Local-first desktop shell; renderer receives no Node or filesystem authority.
- Authentication and authorization are separate: a valid session never bypasses kernel policy.
- Business writes are command-driven, schema-validated, version-checked, audited, and transactionally persisted.
- A legal-entity finance binding is explicit: the India operating profile cannot silently post to a mismatched company, and a posted journal is corrected only through a separately posted reversal.
- Secrets and attachments are encrypted; raw session tokens and vault keys are never exposed to the renderer.
- External repository reuse must follow `THIRD_PARTY_REUSE.md`; incompatible copyleft code is studied or isolated rather than silently copied into the MIT core.
